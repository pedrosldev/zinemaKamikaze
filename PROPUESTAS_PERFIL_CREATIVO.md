```
📊 CASE STUDY: Diseñando un sistema de emociones en código

🎯 Challenge:
Crear 7 estados emocionales (dread, excitement, curiosity, fear, boredom, 
neutral, surprise) que sean:
- Visualmente DISTINTOS pero COHERENTES
- Técnicamente ESCALABLES
- Emocionalmente PRECISOS

🔍 Research:
Analicé teoría del color emocional + psicología cinematográfica:
→ Dread = Tonos oscuros/fríos, tensión
→ Excitement = Brillante/cálido, energía
→ Curiosity = Equilibrado, invitante
[etc.]

🎨 Solución:

1. PALETA EMOCIONAL
Cada mood tiene:
→ Color primario
→ Color de acento
→ Gradiente característico

2. TIPOGRAFÍA CONTEXTUAL
→ Font-weight varía según intensidad emocional
→ Spacing refleja la "respiración" del mood

3. ANIMACIONES NARRATIVAS
Cada mood tiene secuencia de flipbook única:
→ Dread: Imágenes progresivamente más oscuras
→ Excitement: Explosión de color
→ Curiosity: Revelación gradual

4. IMPLEMENTACIÓN
// Estructura en config/moodSequences.ts
export const moodSequences = {
  dread: ['img1.jpg', 'img2.jpg', ...],
  excitement: [...],
  // etc.
}

// Uso en componentes
const sequence = moodSequences[currentMood] || defaultSequence;

[Grid de imágenes mostrando los 7 moods side by side]

📈 Resultado:
→ Sistema consistente pero expresivo
→ Fácil de mantener y extender
→ Los usuarios SIENTEN la diferencia

💼 Takeaway:
El buen diseño de sistemas no es solo "componentes bonitos".
Es PENSAMIENTO ESTRUCTURADO + SENSIBILIDAD ESTÉTICA.

- Tiempo promedio entre token publicado y uso
- Engagement en críticas (lecturas, comentarios)
- Fuentes de tráfico de tokens (¿qué red funciona mejor?)

**Fase Comunidad Centralizada** (v1.5):
- Usuarios registrados vs visitantes anónimos
- Tasa de opt-in para notificaciones
- Open rate de emails/notificaciones
- Retención de usuarios entre ciclos (semana a semana)
- Tiempo de respuesta a notificación de nuevo token
- Engagement de usuarios registrados vs no registrados

**Fase Engagement Avanzado** (v2.0):
- Participación en votaciones/predicciones
- Uso de PWA vs web normal
- Consumo de podcast vs texto
- Posiciones en leaderboard más buscadas

**Fase Plataforma** (v3.0 - si llegas):
- Críticos activos mensualmente
- Tokens generados totales
- Network effects (usuarios que siguen a múltiples críticos)
- Time to first token use (para nuevos críticos)
- Churn de críticos y usuarios
